Build a complete responsive frontend for a LOAN MANAGEMENT SYSTEM using React + TypeScript + Vite.

IMPORTANT:
- Frontend only. Do NOT create a backend.
- Use mock data/localStorage for all functionality.
- Do not use external APIs.
- Keep the code simple and production-like.
- Use clean modern fintech UI with white/light background, blue primary color, cards, tables and responsive layout.
- Create reusable components.
- Make all buttons and navigation functional.
- Do not over-engineer or add unnecessary features.

There are TWO interfaces:

========================================
1. CUSTOMER FACING APP
========================================

Routes/pages:

A. Home
- Logo/brand name
- Register button
- Sign In button
- Simple professional loan/financial landing page

B. Registration Page
Create a registration form with:
- First Name
- Last Name
- Date of Birth
- Residential Address
- PAN Number
- Phone Number
- Email
- Username
- Password
- Confirm Password
- Bank Account Number
- IFSC Code
- Bank Name
- Submit/Register button

After registration show OTP verification screen.

C. OTP Verification
- Email OTP input
- Phone OTP input
- Verify/Confirm button
- Resend OTP
- For demo, accept any 6-digit OTP.

D. Customer Login
- Username
- Password
- Login button
- Forgot Password
- After login redirect to Customer Dashboard.

E. Customer Dashboard
Sidebar/navigation:
- Dashboard
- My Requests
- My Profile
- New Loan Request
- Logout

Dashboard should show:
- Total Loan Requests
- Under Review
- Approved
- Rejected
- Active Loan
- Outstanding Amount

F. New Loan Request
Create a loan application form containing:
- Loan Type dropdown
- Requested Loan Amount
- Loan Tenure
- Interest Rate (auto-calculated/displayed)
- Repayment Frequency
- Repayment Method
- Collateral/Security details
- Additional comments
- EMI/estimated repayment summary
- Submit Loan Request button

After submission show success message and set status to "Under Review".

G. My Requests
Show loan applications in a table/cards:
- Request ID
- Loan Type
- Amount
- Tenure
- Interest Rate
- EMI
- Date
- Status

Statuses:
- Under Review
- Approved
- Rejected
- Disbursed
- Closed

Allow customer to open a request and view complete details and admin comments.

H. My Profile
Show registered customer details and bank details.

========================================
2. INTERNAL ADMIN PANEL
========================================

Admin routes should be separate from customer routes.

A. Admin Login
- Admin Employee ID / Email
- Password
- Forgot Password
- Login button

Use demo credentials:
Employee ID: admin001
Password: admin123

B. Admin Dashboard

Show KPI cards:
- Total Customers
- Under Review
- Approved
- Declined
- Total Disbursed
- Active Loans
- Outstanding Amount
- Overdue Loans

Also include:
- Recent Loan Requests table
- Loan status distribution
- Recent activity

C. Loan Requests / Applications
Admin can see all loan requests.

Table columns:
- Request ID
- Customer
- Loan Type
- Requested Amount
- Tenure
- Interest Rate
- Repayment Method
- Date
- Status
- Action

Clicking a request opens a detailed application page/modal showing the SAME loan details as the customer loan request page.

Admin actions:
- Approve
- Reject
- Add Comment
- Mark as Disbursed
- Mark as Closed

Status flow:
Under Review → Approved → Disbursed → Closed
Under Review → Rejected

D. Customer Management
Show:
- Customer name
- Email
- Phone
- Registration date
- Number of loans
- Active loans
- Status

E. Admin navigation
Sidebar:
- Dashboard
- Loan Requests
- Customers
- Disbursed Loans
- Reports
- Logout

========================================
DESIGN REQUIREMENTS
========================================

Create a professional banking/fintech dashboard.

Use:
- React
- TypeScript
- Vite
- React Router
- CSS/Tailwind if already available, otherwise normal CSS
- Lucide icons if available

Responsive for desktop, tablet and mobile.

Use status badges:
Under Review, Approved, Rejected, Disbursed, Closed.

Use realistic mock customer and loan data so the dashboard looks populated.

Use localStorage so:
- Registration data persists
- Login works
- Loan requests persist
- Admin status changes reflect in customer dashboard

IMPORTANT:
Do not build backend, database, authentication server, payment gateway, or API integration.

First create the complete working frontend structure and all pages. Make sure npm run dev works without errors.
